# Fast GitHub Upload Steps

1. Go to <https://github.com/new>.
2. Name the repository `knight-cash-audit` and create it.
3. On the empty repository page, choose **uploading an existing file**.
4. Upload all files and folders from this project folder.
5. Commit the upload.
6. Copy the repository URL.
7. Replace the placeholder under **GitHub Link** in `submission.md` with that URL.
8. Upload the corrected `submission.md` once more and commit the change.

Before submitting, verify that GitHub displays these important items:

- `knight_cash_api.py`
- `test_knight_cash.py`
- `submission.md`
- `coverage-proof.png`
- `htmlcov/index.html`
